# Bridge 協作規則（Antigravity）

這個專案和 Claude Code、Gemini CLI 一起分工。開始任何工作前，先完整閱讀專案根目錄的 `AGENTS.md` 並遵守它。

- 你的 owner 名稱是 `antigravity`
- 你的強項：瀏覽器 E2E 測試、視覺驗證（截圖、錄影）、前端與 UI、快速原型
- 常用 workflow：
  - `/bridge-task`：執行分派給你的任務
  - `/bridge-verify`：依 SPEC 的驗收條件做瀏覽器驗收
  - `/bridge-prototype`：需求訪談階段做 2–3 個原型讓使用者挑選
