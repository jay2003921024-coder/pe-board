# 網頁專案：要釐清的事與常見盲點

## 通常要問（若無法推論）
- 部署在哪：只在本機跑 / 免費託管（GitHub Pages、Vercel）/ 自己的伺服器
- 需不需要帳號登入？多人資料要不要隔離？
- 資料存在哪：瀏覽器本機（localStorage）/ 後端資料庫 / 第三方（Google Sheets、Notion）
- 主要裝置：桌機 / 手機 / 兩者都要

## 常見盲點（列進假設表）
- 手機版排版
- 資料遺失：重新整理、關掉分頁後資料還在嗎？
- 空狀態：第一次打開、沒有資料時畫面長什麼樣
- 錯誤狀態：網路斷線、API 失敗時的提示
- 深色模式
- 多語系（只要中文？）
- 隱私：會不會存到他人的個資？

## 適合做原型的部分
首頁或主畫面的版面、核心操作流程（3 步以內能完成嗎？）

## AC 範例
- AC-n：Given 手機寬度 375px，When 打開首頁，Then 沒有水平捲軸，主要按鈕可點擊
- AC-n：Given 已新增 3 筆資料，When 重新整理頁面，Then 3 筆資料仍在
