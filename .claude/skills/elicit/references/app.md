# App 專案（桌面／手機）：要釐清的事與常見盲點

## 通常要問（若無法推論）
- 平台：Android / iOS / 兩者 / 桌面（Windows、macOS、Linux）
- 技術路線偏好：原生 / 跨平台（Flutter、React Native）/ 網頁包成 App（PWA、Tauri、Electron）
  → 若使用者沒偏好，依 USER_PROFILE 推薦，寫成假設
- 需不需要離線使用？
- 會用到裝置功能嗎：相機、定位、通知、檔案存取
- 要上架商店，還是自己安裝就好？

## 常見盲點（列進假設表）
- 權限被拒絕時怎麼辦（相機、通知）
- App 被切到背景、被系統殺掉後，狀態能恢復嗎？
- 不同螢幕尺寸、橫直向
- 資料同步：多台裝置之間要同步嗎？
- 更新：之後怎麼發新版本
- 上架審核的要求（隱私權政策等）

## 適合做原型的部分
主要畫面與導覽結構（tab？側邊選單？），核心操作的點擊次數。可以先用 HTML 模擬手機畫面。

## AC 範例
- AC-n：Given 首次開啟且拒絕通知權限，When 進入設定頁，Then 顯示「通知已關閉」與前往系統設定的按鈕
- AC-n：Given 編輯到一半，When 切到背景 5 分鐘後回來，Then 編輯內容仍在
