# 需求規格

> 由 `/elicit` 填寫。核准後鎖定，之後只能透過 `bridge.py change` 提出變更。

## 現況（既有專案才填）

單檔網頁 `pe-board.html`（約 1600 行，HTML＋CSS＋原生 JS，無建置流程），體育老師用來畫教案戰術圖：
- 14 種場地（籃球半／全場、排球、羽球、桌球、網球、足球、手球、躲避球、壘球、田徑、體育館、草地、游泳池），以 SVG 依公尺比例繪製
- 工具：學生（五色隊伍）、老師、三角錐、標誌盤、球、呼拉圈、跨欄、繩梯、小球門、軟墊、浮板、文字；跑動／傳球／運球線、區域；快捷鍵、多選、復原／重做
- 多步驟教案：每步有名稱與活動說明；可播放步驟間的移動動畫
- 匯出 PNG（目前步驟，或全部步驟＋說明），可複製貼到 Word／簡報
- 範本庫：內建範本、我的範本（資料夾）、在 Claude Artifact 環境下可共享給其他老師（`window.claude` db）；非 Artifact 環境退回 localStorage；可匯出／匯入範本 JSON
- 執行方式：直接用瀏覽器開啟 `pe-board.html`

必須保留的既有行為：
- 目前編輯中的教案存在 localStorage `pe-board-v1`，我的範本存在 `pe-board-mytpl-v1`；改版後舊資料要能讀
- 範本匯出檔格式 `{ app: 'pe-board', version: 1, templates: [...] }` 要能被匯入
- 單檔、直接開啟即可使用
- 既有場地、工具、快捷鍵、匯出 PNG、動畫播放

## 一句話目標

把單檔的 `pe-board.html` 重構成好維護的多檔靜態網站，部署到 GitHub Pages 公開給所有體育老師使用；同時讓平板觸控好畫，並加上「Google 登入後可發布到線上共享區、未登入可瀏覽套用與用檔案匯入匯出」的範本分享。

## 使用者與情境

- 公開給所有體育老師（國小到高中），不需要先申請帳號就能畫圖、匯出圖片
- 備課時用桌機／筆電（滑鼠＋鍵盤）；上課現場或移動中用平板（手指觸控）
- 想分享範本的老師用 Google 帳號登入後發布；其他老師不登入也能瀏覽、套用
- 管理員（專案擁有者）負責下架不當內容

## 成功的樣子

- 既有功能在新版全部照舊可用，老師感覺不到「改壞了」
- 在 iPad 上不用鍵盤，只靠手指就能完成一張多步驟教案並匯出
- 老師打開共享區就看得到可用的範本，登入發布兩三步就完成
- 之後要加場地、工具或修 bug 時，只需要改對應的小檔案，且有測試保護

## 驗收條件（AC）

### 回歸：必須保留的既有行為

- AC-1 [必要]：Given 新版部署完成，When 逐一切換 14 種場地，Then 每種場地都正確繪出，名稱、分組與舊版相同
- AC-2 [必要]：Given 任一場地，When 使用每一種工具（學生五色、老師、三角錐、標誌盤、球、呼拉圈、跨欄、繩梯、小球門、軟墊、浮板、文字、跑動／傳球／運球線、區域）放置與拖曳，Then 都能建立、選取、移動、刪除，外觀與舊版一致
- AC-3 [必要]：Given 桌機瀏覽器，When 按舊版的快捷鍵（V／S／T／C／B／X／R／P／D／Z、Ctrl+Z、Ctrl+Shift+Z、Esc、Delete），Then 行為與舊版相同
- AC-4 [必要]：Given 有 3 個步驟的教案，When 新增／切換／刪除步驟、編輯步驟名稱與活動說明、按「播放動畫」並切換 0.5×／1×／2×，Then 行為與舊版相同
- AC-5 [必要]：Given 同一份教案，When 分別以「目前步驟」與「全部步驟＋說明」匯出 PNG，Then 圖片內容與版面與舊版匯出的相同（允許字型反鋸齒等像素級差異），「複製圖片」可貼進 Google 文件
- AC-6 [必要]：Given 瀏覽器 localStorage 中已有舊版寫入的 `pe-board-v1`（編輯中教案）與 `pe-board-mytpl-v1`（我的範本與資料夾），When 第一次在同一網域打開新版，Then 教案與我的範本、資料夾完整出現，不需任何操作
- AC-7 [必要]：Given 舊版匯出的範本檔（`{ app: 'pe-board', version: 1, templates: [...] }`），When 在新版「匯入範本檔」，Then 所有範本正確匯入並可開啟；新版匯出的檔案也能被新版匯入
- AC-8 [必要]：Given 內建範本，When 從範本庫套用，Then 內容與舊版相同
- AC-9 [必要]：Given 深色模式的系統設定，When 打開網站，Then 套用深色配色，且所有文字可讀

### 部署與結構

- AC-10 [必要]：Given repo 推到 GitHub 並開啟 GitHub Pages，When 用 Chrome、Safari（含 iPadOS）、Edge 開啟網址，Then 不需任何建置步驟即可正常使用全部功能
- AC-11 [必要]：Given 開發者在本機，When 用一行指令啟動靜態伺服器（例如 `python3 -m http.server`），Then 可開啟並使用全部功能；README 寫明這個指令
- AC-12 [必要]：Given 重構後的程式碼，When 檢視目錄，Then 場地定義、工具／圖示、繪圖、編輯互動、動畫、匯出、範本庫、雲端同步各自位於獨立模組，單一檔案不超過 400 行
- AC-13 [必要]：Given 本機已安裝 Node.js，When 執行 README 寫的一行測試指令，Then 單元測試全部通過，且不需要 `npm install` 以外的建置步驟；測試至少涵蓋：教案資料正規化（含舊版資料）、範本檔匯入／匯出、復原／重做、動畫步驟間物件配對

### 平板觸控

- AC-14 [必要]：Given iPad 橫向（1024×768）與直向（768×1024），When 開啟網站，Then 沒有水平捲軸，畫布與工具列同時可見，所有可點按鈕的觸控區至少 44×44 px
- AC-15 [必要]：Given 平板只用手指，When 點選工具後點畫布放置物件、拖曳物件、拖曳線條端點與控制點、點空白處取消選取，Then 都能一次成功，不會誤觸成捲動頁面或放大頁面
- AC-16 [必要]：Given 平板沒有鍵盤，When 要復原、重做、刪除、複製、多選物件，Then 都有畫面上的按鈕或手勢可以完成
- AC-17 [必要]：Given 平板，When 編輯文字物件或步驟說明，Then 跳出的螢幕鍵盤不會遮住正在輸入的欄位
- AC-18 [加分]：Given 平板，When 在畫布上雙指捏合／拖曳，Then 畫布縮放與平移，放開後可一鍵回到原尺寸；匯出圖片不受縮放影響

### 登入與線上共享區

- AC-19 [必要]：Given 未登入，When 打開範本庫的「共享區」，Then 可以瀏覽、搜尋（依名稱）、預覽並套用其他老師發布的範本，不會被要求登入
- AC-20 [必要]：Given 未登入，When 按「發布到共享區」，Then 提示需要 Google 登入；登入完成後回到原畫面，正在編輯的教案內容不遺失
- AC-21 [必要]：Given 使用者已有 Google 帳號，When 從按下「登入」到完成，Then 最多 2 次點擊（登入按鈕＋選擇帳號）；登入後頂端顯示使用者名稱與「登出」
- AC-22 [必要]：Given 已登入，When 把一個範本發布到共享區，Then 不重新整理頁面，另一台未登入的裝置在 10 秒內重新開啟共享區即可看到，並顯示作者名稱與發布時間
- AC-23 [必要]：Given 已登入的作者，When 修改或刪除自己發布的範本，Then 共享區同步更新；Given 已登入但不是作者也不是管理員，When 嘗試修改或刪除別人的範本（含直接呼叫後端），Then 被後端規則拒絕
- AC-24 [必要]：Given 管理員帳號，When 在共享區對任何範本按「下架」，Then 該範本從共享區消失；非管理員看不到「下架」按鈕
- AC-25 [必要]：Given 未登入者，When 嘗試直接對後端寫入任何資料，Then 被後端規則拒絕
- AC-26 [必要]：Given 共享區還沒有任何老師發布範本，When 打開共享區，Then 顯示說明文字，並提供內建範本與「發布第一個範本」的入口，而不是空白畫面
- AC-27 [必要]：Given 網路斷線或 Firebase 無法連線，When 使用網站，Then 畫圖、匯出圖片、我的範本（本機）、檔案匯入匯出都照常可用，共享區顯示「暫時連不到共享區」提示
- AC-28 [必要]：Given 已登入，When 打開「我的範本」，Then 範本存在雲端並在同帳號的其他裝置看得到；第一次登入時，本機既有的「我的範本」會自動上傳到雲端，本機副本保留不刪
- AC-29 [加分]：Given 共享區範本超過 50 個，When 瀏覽，Then 可以依場地篩選，並分頁或捲動載入

## 非目標（這次不做）

- 不重寫繪圖與動畫的行為、不重新設計整體版面或配色：只做必要的結構拆分與平板相關調整
- 不新增場地、工具種類或匯出格式（PDF、影片等）
- 不改用前端框架（React、Vue 等）或需要建置的工具鏈（Vite、TypeScript、打包器）
- 不支援 Google 以外的登入方式，不做帳號註冊、密碼、個人頁面
- 不做共享區的發布前審核、留言、評分、按讚、檢舉流程
- 不搬移舊 Claude Artifact 雲端裡的共享範本（需要的人先在舊版匯出檔案，再到新版匯入）
- 不保證以 `file://` 直接雙擊開啟 HTML 可用（改以 GitHub Pages 網址或本機靜態伺服器為準）
- 不做手機版的完整編輯體驗（手機只需能開啟、瀏覽、匯出，不跑版）
- 不做多語系，只有繁體中文

## 限制（使用者指定的技術、時程、環境）

- 部署：GitHub Pages（純靜態）
- 前端：多檔原生 JavaScript ES modules，無建置步驟
- 登入與雲端：Firebase（Google 登入＋Firestore），以 CDN 載入
- 裝置：桌機與平板都要好用
- 核心邏輯需有自動化單元測試

## 事前驗屍：最可能讓使用者失望的原因

使用者回答了三項，各自對應的保護：

1. **重構後舊功能壞掉或變難用** → AC-1～AC-9 逐項回歸驗收；AC-13 單元測試；非目標明定不改行為與版面
2. **平板上還是不好畫** → AC-14～AC-17（必要）、AC-18（加分），需在真實平板或模擬器上驗收
3. **共享區空空的或登入很麻煩** → AC-19（不登入也能看）、AC-21（2 次點擊登入）、AC-20（登入不遺失內容）、AC-26（空狀態有內容與入口）
