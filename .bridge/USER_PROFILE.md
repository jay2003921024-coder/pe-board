# 使用者偏好

> 跨專案共用。`/elicit` 會在訪談後補充；你也可以直接編輯。
> 建議把這個檔案的「正本」放在一個固定位置，新專案 init 時複製過來。

## 技術棧偏好

- 前端偏好多檔原生 JS（ES modules），不要建置步驟
- 靜態網站部署偏好 GitHub Pages
- 需要登入／雲端時選 Firebase（Google 登入＋Firestore）
- 要有核心邏輯的單元測試

## 風格偏好（UI、程式碼、文件）

## 我通常在乎的事

- 重構後舊功能不能壞、不能變難用
- 平板觸控要好用（桌機與平板並重）
- 分享功能要低門檻：未登入也能瀏覽套用，登入步驟要少
