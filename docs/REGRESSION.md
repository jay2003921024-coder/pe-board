### AC-5　匯出 PNG、複製圖片

### AC-28　登入後我的範本雲端同步、首次登入自動上傳

- 前置狀態：裝置 A 未登入時已有本機「我的範本」；之後登入。
- 操作步驟：裝置 A 登入 → 打開「我的範本」；裝置 B（同帳號）登入後打開「我的範本」。
- 預期結果：範本存在雲端並在同帳號的其他裝置看得到；第一次登入時，本機既有的「我的範本」自動上傳到雲端，本機副本保留不刪。
- 驗證者：
  - 上傳計畫與資料夾合併邏輯：`npm test`（`tests/unit/share.test.js` 的 `planFolderMerge`）。
  - 實際雲端讀寫（首次登入上傳、`users/{uid}/templates` 只限本人）：`npm run test:rules`（`AC-28` 測試）。
  - 跨裝置／同帳號在真實瀏覽器中的整體流程：e2e（同一台機器開兩個瀏覽器設定檔，用同一 Google 帳號各登入一次）。

### AC-29　共享區依場地篩選＋分頁（加分）

- 前置狀態：共享區範本超過 50 個（可用 emulator 或測試資料灌入）。
- 操作步驟：瀏覽共享區，依場地篩選，捲動或按「載入更多」翻頁。
- 預期結果：可以依場地篩選，並分頁或捲動載入；正式環境篩選不出現 `FAILED_PRECONDITION`（需要 `firestore.indexes.json` 的複合索引已部署並顯示「已啟用」）。
- 驗證者：
  - 篩選／分頁邏輯：`npm test`（`share.test.js` 的 `filterShared`／分頁）＋ `npm run test:rules`（`AC-29`：依場地篩選、分頁 cursor）。
  - **正式環境索引是否真的生效：真機人工／010 在正式 Pages 網址上實測**（見下方「正式環境自測」）。
